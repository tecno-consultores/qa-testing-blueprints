# Changelog — `@sinfallas/mcp-qa-11x`

All notable changes to the `@sinfallas/mcp-qa-11x` npm package and MCP server are documented in this file.

## [Unreleased]

### Added
- **SSR Dual-ColorScheme Hydration Audit (`QA-SSR-HYDRATION-01`), `vendor` Exclusion, `ephemeral-runner.ts` Shell/Teardown Hardening & `QA-HEALTH-01` Precision:** Added rule #34 `QA-SSR-HYDRATION-01` in `src/tools/security-auditor.ts` and `src/server.ts` scoped strictly to SSR/SSG + dynamic-theme projects; excluded `vendor` (and `target`/`graphify-out`) in `IGNORED_DIRS` and `src/tools/inspect-project.ts`; hardened `src/tools/ephemeral-runner.ts` with `hasUnquotedShellSyntax`, cumulative timeout budget deduction, and automatic `compose down -v --remove-orphans` teardown after `up -d`; and tightened `QA-HEALTH-01` for multiline `.done()`/`.cancelled()` supervisor checks and per-function unmocked probe assertions (`535` unit tests, `33` Karate scenarios).
- **Playwright Exact Version Parity (`QA-PLAYWRIGHT-PIN-01`), Non-Root `ui-e2e` Alignment & `QA-HEALTH-01` Report Exclusions:** Added `checkQaPlaywrightPin01VersionParity` in `src/tools/security-auditor.ts` (`33` static rules) and exact Playwright alignment (`alignExactPlaywrightVersion`) in `SurgicalMerger.mergePackageJson()`, aligned `example/frontend/package.json` (`1.52.0`), added `/tmp/chaos`, `/tmp/lhci`, `/tmp/psi`, `/tmp/report` + log/report extension exclusions in `QA-HEALTH-01` and `psi-reports`/`psi-report.json` cleanup in `clean_workspace_11x`, and expanded `run_ephemeral_qa` with recursive `$(MAKE) -C` delegation (`--project-directory`, containment guard) plus Node/Frontend (`ui`/`ui-e2e`) and Python direct Compose fallbacks.
- **Rule-Zero Docker Fallback When GNU `make` Is Unavailable (`src/tools/ephemeral-runner.ts`):** Added a fail-closed fallback in `run_ephemeral_qa` that expands declared `Makefile` variables/dependencies or maps `docker-compose.qa.yml` when `make` fails with `ENOENT` (or `Makefile` is absent), executing strictly `docker compose` / `docker run` commands with `shell: false` and rejecting host-side non-Docker recipes.
- **Real-Runtime SDK Transport & Lockfile Image Smoke Audits (`QA-CONTRACT-SDK-01`, `QA-DOCKER-LOCK-01`) + False-Positive Tuning:** Added `checkQaContractSdk01RealTransport` (requiring in-process SDK client transport contract tests alongside handler unit tests) and `checkQaDockerLock01LockfileAndSmoke` (enforcing lockfile-pinned `Dockerfile` installs and post-build image smoke verification) in `src/tools/security-auditor.ts`, scoped `QA-HEALTH-01` probe extraction strictly to `HEALTHCHECK`/`healthcheck:` blocks (ignoring `/tmp/venv` and helper scripts), and exempted deployment env templates (`env.example`, `.env*.example`) in `src/tools/certify-gate.ts`.
- **GitHub Actions Shell Escape & Sub-Makefile `CURDIR` Audits (`QA-CI-ESCAPE-01`, `QA-MAKE-CURDIR-01`):** Added `checkQaCiEscape01WorkflowExpansion` and `checkQaMakeCurdir01SubMakefile` in `audit_security_stig_owasp` (`src/tools/security-auditor.ts`) to block Makefile/Compose double-dollar expansions (`$$(...)`, `$${...}`) inside `.github/workflows/*.{yml,yaml}` / `.github/actions/*/action.{yml,yaml}` `run:` steps (expanding `$$` to bash PID and breaking Docker volumes with `exit code 125`) and inherited `$(PWD)` / `${PWD}` references in subdirectory `Makefile`s (`*/Makefile`, `*/Makefile.example`), enforcing `$(CURDIR)` (with `qa-ci-escape-ok` / `qa-make-curdir-ok` pragmas).
- **Multi-Format Favicon, PWA Manifest & Edge `_headers` Audit (`UI-11X-03`):** Added `checkUi11x03FaviconPwaAndEdgeHeaders` in `audit_security_stig_owasp` (`src/tools/security-auditor.ts`) to detect `.webp`/`.svg` `apple-touch-icon` links, missing `favicon.ico` (`>= 48x48`) or broken `404` icon declarations in `index.html`, `.webp` or combined `"any maskable"` entries in `.webmanifest`/`public/manifest.json`, Cloudflare Pages `_headers` overrides missing `! <Header>` detachment (`Cross-Origin-Resource-Policy: cross-origin`), and invalid suffix globs (`/*.ico`) in `_routes.json`.
- **Non-Interactive Compose TTY & Read-Only Wrangler Audit (`QA-DOCKER-TTY-01`):** Added `checkQaDockerTty01NonInteractiveAndReadOnly` in `audit_security_stig_owasp` (`src/tools/security-auditor.ts`) to detect `docker compose run` invocations missing `-T`/`--no-TTY` in CI/deploy workflows and scripts (`CI=true`), `read_only: true` Compose services running `wrangler` without a `noexec` `.wrangler` `tmpfs` mount, and `wrangler pages deploy`/`project create` commands under `CI=true` missing `--force` (with `qa-docker-tty-ok` pragma exemptions).
- **GitHub Actions SHA-40 Pinning Audit (`SEC-CI-ACTION-REF`):** Added `checkSecCiActionRef` in `audit_security_stig_owasp` (`src/tools/security-auditor.ts`) to flag mutable branches (`@main`, `@master`) and unprefixed legacy tags (`aquasecurity/trivy-action@0.x.y`) in `.github/workflows/*.{yml,yaml}` and `.github/actions/*/action.{yml,yaml}` while exempting local paths, `docker://`, and `# sec-ci-action-ref-ok` (including `quickstart` PR workflow templates).
