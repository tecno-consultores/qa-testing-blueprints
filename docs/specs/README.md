## 2. Maintenance Policy & Scope Clarifications (Spec 19)

- **Historical Spanish Archival ADRs (`Specs 01–18`):** Preserved in Spanish as immutable architectural records (`v1.x`/`v2.x` point-in-time design snapshots, exempt from bilingual EN/ES mirroring per [`19_SPEC`](19_SPEC_PLAN_ARQUITECTURA_BILINGUE_EN_PRIMARIO_Y_ESPEJO_ES.md) §3, Rule 4). Earlier component counts inside frozen ADRs (such as earlier pre-v3.2 skill, rule, and tool totals) reflect their authoring milestone; only archival notices, unified status headers (`IMPLEMENTED AND CERTIFIED`), safety/regex clarifications, and moved document paths (such as `docs/05_ARQUITECTURA_Y_GOBERNANZA_AGENTES_IA.md`) are maintained to guarantee zero broken links.
- **v3.0+ Specifications & Active `v3.5` Evolution (`Specs 19–20+`):** Authored as canonical English (`*.md`) + 1:1 Spanish Mirror (`*.es.md`) pairs linked from [`README.md`](../../README.md) (and `README.es.md`). Post-Spec-20 evolutionary `v3.1`–`v3.5` additions (the 11th skill `tactical-patterns-11x`, Tool 19 `session_flight_recorder`, Resource 13 `blueprint://skills/tactical-patterns-11x`, 8th rule `git_closure_gate.md`, declarative AST boundaries, and longitudinal Git signals) are governed directly in [`CHANGELOG.md`](../../CHANGELOG.md), [`ROADMAP.md`](../../ROADMAP.md), and [`docs/05_ARQUITECTURA_Y_GOBERNANZA_AGENTES_IA.md`](../05_ARQUITECTURA_Y_GOBERNANZA_AGENTES_IA.md), reflecting the active **19 Tools**, **13 Resources**, **11 modular skills**, **8 rules**, and **10 stacks** surface.

### `16_SPEC` Implementation Scope vs. Roadmap Milestone 21 (`verify_diff_coverage.py`)

- **Point-in-Time Spec vs. Active Codebase:** `16_SPEC` was originally authored as Delivery 1 of the Milestone 21–23 triad (when the MCP server was still on its pre-v3.1 surface). All **6 tasks (`21.1–21.6`) of Roadmap Milestone 21** are **100% implemented and certified** in [`ROADMAP.md`](../../ROADMAP.md):
  - **Root `Makefile`:** `test-mcp` exports `.agents/.cache/coverage/mcp-server.info` (LCOV) and `test-py` exports `.agents/.cache/coverage/python.xml` (Cobertura XML); `make diff-cov` runs `.agents/scripts/verify_diff_coverage.py` inside ephemeral Docker (`Rule Zero`).
  - **Multi-Stack MCP Harvesting (`ephemeral-runner.ts`):** `harvestCoverageReports()` collects `ROOT_COVERAGE_CANDIDATES` (`coverage.xml`, `coverage/cobertura-coverage.xml` -> `node-cobertura.xml`, `build/logs/cobertura.xml` and `coverage/clover.xml` -> `php.xml`, `coverage_report/{kcov-merged/,}cobertura.xml` -> `bash.xml`, and `coverage/lcov.info`) plus `{subDir}/coverage.xml` and `{subDir}/coverage/lcov.info` (rebased via `rewriteLcovSubdirPrefix()`) across `MONOREPO_COVERAGE_SUBDIRS`, writing `0600` files to `.agents/.cache/coverage/` during `unit`, `ci`, and `all` stages of `run_ephemeral_qa`.
  - **Conditional Gate Behavior (`certify_task_completion.sh`):** Stage execution invokes `verify_diff_coverage.py` whenever cached coverage reports exist in `.agents/.cache/coverage/` and cleanly reports `SKIPPED` when run standalone without cached coverage artifacts (Zero Hardcoded Pass).
